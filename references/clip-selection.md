# 台词提取 · 音频对齐 · 字幕遮挡 · 片源准备（完整操作手册）

本文档是 Ivan Learning 课程素材产线的完整规范：选片段 → 核台词 → 下载片源 → 还原真实台词 → 对齐时间轴 → 裁剪无字幕视频/音频 → poster。**顺序不可颠倒，任何一步不可跳过**。所有模型按此执行，产出与官方课程一致。

## 1. 选片段（30 秒内定夺）

- 知名梗/名场面（Family Guy 的 Cool Whip、Shoot me in the foot、Giggity 等；辛普森、瑞克和莫蒂、动画电影名场面），学员有动力。
- 对话密集（2 位说话人一来一回最佳），有清晰可教点：发音连读、常用句型、习语、文化梗。
- 避免：纯动作戏、唱段为主、脏话/敏感内容密集。

**等级适配维度**（以 B1 为例：生词率每 30s ≤3 个、短句为主复合句 1-2 句、中速连读弱读点 2-4 处、梗能用 1-2 句中文解释）。片长：A1-A2 20-40s；B1 30-60s；B2 45-75s；C1 60-90s。

## 2. 先核台词（先于找片源，顺序不可颠倒）

1. 网搜候选片段台词全文：subslikescript.com / springfieldspringfield.co.uk 等字幕站，关键词 `<剧集名> <季集> <场景关键词> script`。
2. 读全文确认：场景起止、说话人、台词逐字内容、是否有经典梗句。
3. 台词找不到可靠来源 → **换片段**，不凭印象写台词（质量门：台词不编造）。

## 3. 找片源并下载

1. 国内学员优先 B 站：`site:bilibili.com <剧名> <场景/梗关键词>` 搜剪辑/合集（常带硬字幕=后续证据）；YouTube 备选。
2. 用 doubao-video-extract 下载（`python3 scripts/minutes/social_video_to_minutes.py "<url>" --media-mode video`）。优先「正好是目标场景」的短剪辑；合集则需先定位目标段在合集时间轴的位置。
3. 拿到本地 MP4 后，先抽帧定位：目标场景在合集的哪段时间（如第 2 课在 52 分钟合集的 **1008.0–1075.8s**）。

## 4. 还原真实台词（三重校准，防"漏句/对不上"的根）

剪辑/合集**常跳句**——字幕站全文≠实际音频内容。必须三方比对，以**实际音频**为准：

### 4.1 硬字幕 OCR（证据层）
- 对目标时间窗按 1-5s 间隔抽帧（PyAV/mediakit 抽帧），把英文硬字幕读出来（图片识别）。
- 得到"这段视频里实际出现的每一句台词"及大致顺序——硬字幕即最终证据。

### 4.2 云端 ASR（时间轴层，推荐必做）
- 用 mediakit-cli 对**裁剪好的场景音频**做语音识别：`video asr-subtitles`，语言 `eng-US`。
- 返回带时间戳的逐句文字（含 speaker/confidence 字段时参考使用）。
- **关键价值**：快速对吵、连读句时，ASR 能听出**真实句子数和边界**——官方剧本里一句"long sentence"实际可能是 2-3 个快速来回，必须按 ASR 拆成多句 cue，否则学员点一句听到两句话（"语音和文字对不上"）。

### 4.3 三方比对规则
| 来源 | 作用 | 优先级 |
|---|---|---|
| 硬字幕 OCR | 实际音频里有什么（句子集合） | 内容权威 |
| 云端 ASR | 逐句时间戳、句子边界、语速 | 时间轴权威 |
| 字幕站全文 | 说话人、上下文、官方拼写 | 语义权威 |

- 逐句 `s/e` 取自 ASR 时间戳（±0.3s 内校准）；OCR 确认句子内容；字幕站确认 who 与语境。
- 说话人归属：ASR speaker 字段可参考，最终按剧情上下文人工确认（第 2 课三说话人 B/S/O）。
- 剪辑删句时：以实际音频为准出解析，页面注明与官方台词的差异。

## 5. 对齐时间轴（产出 CUES 数据）

1. 每个 cue 一条 ASR 句子；`s`=句首、`e`=句尾（秒，精确到 0.1）。
2. 相邻 cue 边界检查：下一句 `s` - 上一句 `e` ≥ 0.2s；重叠或空隙过大都要回听校准。
3. 整段首句前/末句后裁剪对齐 `FULL_END`（音频总长）。
4. 页面播放器另有防串句逻辑（cueStart 提前 0.05s / cueEnd 多收 0.08s 且不越过下一句 0.03s），见 html-build.md 第 3 节——数据侧仍须把 s/e 对齐准确。

## 6. 字幕遮挡（盲听视频必须无字幕）

源视频带硬字幕（B 站剪辑几乎都带）时，**默认用 boxblur 模糊字幕条区域，不裁剪画面**（保留完整构图；第 3 课起按用户确定的标准执行）：

1. **上下边缘都要抽帧检查**：除底部双语字幕条外，横版合集顶部常有 UP 主中文旁白/注释条（第 2 课真实案例：顶部 y0-45 旁白条 + 底部 y255+ 双语条）。**只模糊台词字幕所在区域**（底部双语条）；顶部平台水印/UP 旁白条不属于台词字幕，按用户偏好默认保留（用户明确要求干净时才一并模糊）。
2. **用 OCR 的 text_location 精确像素坐标定模糊区，勿留大余量**：mediakit `video-ocr --mode Detailed` 返回每段字幕的像素 y 范围（如 640x360 英文字幕 y266-321、中文字幕 y321-359）。**默认只模糊英文字幕行，保留中文行**（学员看中文辅助理解、听英文训练——第 3 课用户确定的标准）：模糊区 = 英文区上下各加 4-6px（如 y260-326，crop 高度须偶数）。**禁止把中英整条都糊**（比英文区多 30px+，用户反馈"还是很大"）。仅当用户明确要求无任何文字时才覆盖中文行。
3. **boxblur 参数三坑（第 3 课真实踩坑，全中过）**：
   - 必须显式写 chroma 参数：`boxblur=24:3` 让 chroma 隐式取 24，但 chroma 半径上限 16 → 报 `Invalid chroma_param radius value 24`；
   - **luma 半径 24 模糊云太大**：半径=24 的模糊向边缘外扩散一圈，视觉上糊条比实际区域大很多（用户连续反馈"模糊区域太大"）。**统一用 `boxblur=10:2:6:2`**——luma 半径 10 对 30px 高的字幕文字足够不可读，且糊条边缘锐利、视觉面积最小（第 3 课最终标准）。
4. **先裁视频（-an）、再裁音频、最后合并**——`filter_complex` 带音频 map 会报 `Failed to inject frame into filter network`（真实踩坑，勿试）：
   ```bash
   # ① 只模糊英文行（示例：英文 y266-321 → 模糊区 y262-322，crop 高度 60；与中文行 y321+ 不重叠）→ 无音频视频
   ffmpeg -ss <起> -to <止> -i src.mp4 \
     -filter_complex "[0:v]split[a][b];[a]crop=640:60:0:262,boxblur=10:2:6:2[mb];[b][mb]overlay=0:262[v]" \
     -map "[v]" -c:v libx264 -crf 26 -preset veryfast -pix_fmt yuv420p -an step1.mp4
   # ② 音频
   ffmpeg -ss <起> -to <止> -i src.mp4 -vn -acodec aac -b:a 96k lesson_audio.m4a
   # ③ 合并（c:v copy）
   ffmpeg -i step1.mp4 -i lesson_audio.m4a -c:v copy -c:a aac -b:a 96k -movflags +faststart blind.mp4
   ```
   需模糊多处时，对 step1 再做一次同款 split/overlay（crop 高度须偶数）。
4. **裁完/模糊完抽帧验证**：字幕区无任何可读英文残留，主体完整。crop 裁剪仅作备选（画面完整性不重要或体积敏感时）。

## 7. 裁剪音频与视频（产物准备）

```bash
# 音频（逐句 cue 与盲听共用，m4a 体积更小）
ffmpeg -ss <起> -to <止> -i src.mp4 -vn -acodec aac -b:a 96k -y lesson_audio.m4a

# 盲听视频（无字幕 + 小体积 + moov 前置！）：先用第 6 节模糊出无字幕视频再合并音频
```

- **`-movflags +faststart` 必须加**：moov 前置，否则内嵌 base64 视频浏览器无法播放（黑屏/duration NaN）。
- 体积目标：30s 片段 ≤1MB（crf 26 起步，超了调 28）；音频 m4a 比 mp3 更小。
- poster：`ffmpeg -i blind.mp4 -frames:v 1 poster.jpg`，压到 20-50KB。

## 8. 版权边界

- 只裁剪 1-2 分钟短片用于个人学习（合理使用范畴）；不下载、不传播、不交付完整剧集。
- 解析、翻译、讲解为原创内容，可自由交付。
