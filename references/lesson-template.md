# 每课交付模板（四步教学法 + 复习闭环）

每次出课按此结构交付，四步缺一不可。语言用学员所用语言（默认中文讲解 + 英文台词）。

## Step 0 · 复习上一课（第 2 次起）

- 开新课前先要求学员用上一课 HTML 页复习：整段盲听重听 → 精听逐句跟读 → 交上节课作业（造句/填空/录音）。
- 批改复习作业，通过才进新课；不通过让学员重练。
- **复习任务下达的同时，并行准备新课**（选片段→核台词→找片源→裁剪音频→做 HTML），学员确认复习完成后一并交付新课页。

## Step 1 · 盲听

- 交付：**内嵌「无字幕视频 + 原声」的单文件 HTML**（present_files 交付整页，不单独交音频）。视频源带硬字幕时，先抽帧确认字幕条位置，用 ffmpeg crop 裁掉字幕条区域再内嵌，保证盲听画面干净无字幕（方法见下方「盲听视频标准」）。
- 给 3-5 个引导问题（谁在说话、在干什么、笑点/情绪在哪、注意哪个发音、结局反转）。
- 要求：看画面听原声 2-3 遍，先不看任何文字。

## Step 2 · 逐句解析

- 交付台词表格：`# | 说话人 | 台词 | 解析`。
- **解析六要素（缺一不可，v1.2 起强制）**：
  1. **发音/连读**：写音标或拟音（如 What'd you say → /wʌʤə/、t 失爆、弱读）；
  2. **词汇**：本句生词/多义词，给中文释义；
  3. **常用词组/短语搭配（必写）**：本句含的核心短语（如 point A at B、flat out、can't have A without B），标出"词组"并给中文；
  4. **句型**：本句的可复用句式（如 Don't + 动词原形、This is flat out + 形容词），一句话说明用法；
  5. **文化梗**：笑点机制 + 背景（如双关、习语字面义 vs 实际义）；
  6. **造句示例（必写 1-2 个）**：用本课词组/句型造贴近日常生活的句子，附中文，供学员模仿。
- 解析内容必须与实际音频一致；字幕与官方台词有差异时标注。
- 结尾给「知识点小结」：词汇、发音、常用词组、句型、文化梗五条。

## Step 3 · 带字幕精听

- 交付：**干净双语脚本**（英文台词逐句 + 中文对照，无解析），即"字幕"。
- 步骤（写清楚让学员照做）：
  1. 对照字幕把音频再听一遍，逐句找到刚才盲听时没听出来的地方，标记；
  2. 跟着音频逐句跟读 2 遍（模仿语气、连读）；
  3. 关掉字幕再裸听 1 遍，确认每一句都能听清。
- 可附填空练习（挖 8 个左右关键词）供自测。

## Step 4 · 监督与反馈（可选，学员同意才建）

1. 问：每天可学多久？几点方便提醒？
2. 按定时任务 Skill（doubao-cron-scheduler）建每日打卡提醒。
3. 布置作业：填空答案 + 理解题英文回答 + 用本课句型造句（2-3 句）＋（可选）30 秒跟读录音。
4. 学员交作业后：批改、纠音、按表现决定下一课难度（达标升档，不达标重练）。

## 交互学习页（每课默认交付，单文件 HTML）

按 html Skill 制作**一个自包含的 .html**（内嵌 base64 视频 + 音频，无外部依赖），把三步收进一页，学员在手机/电脑直接打开：

- **盲听区**：内嵌 `<video>`（**无字幕画面** + 原声）+ 播放按钮 + 引导问题（先不给字幕和解析）。
- **精讲区**：逐句台词卡（条数 = 实际台词数，如 28 条），**点击任意一句播放该句原音**（同一份音频按 cue 时间轴 seek 播放），可展开解析；每句解析含**连读技巧标注**（失爆/同化/弱读/元音+元音连读，写音标或拟音），附发音/知识点对比卡（如 /w/ vs /hw/）。
- **精听区**：逐句播放面板——**语速选择（0.5×/0.75×/1×/1.25×）、上一句/下一句、单句循环**、句内进度条、音量控制。
- 交互规范：播放必须由用户点击触发（禁止自动播放）；按钮 ≥44px；所有按钮挂真实 handler；无 emoji。
- 台词时间轴：**字幕站全文 + 视频硬字幕 OCR + 云端 ASR（mediakit-cli video asr-subtitles）三重校准**逐句对齐（±0.3 秒误差，页脚注明口径）。

### 生产规避清单（模板派生时必查，第 2 课踩过的坑）

1. **base64 变量必须替换本体，禁止只改 src 前缀**：模板的 JS 是 `audio.src = "data:audio/mpeg;base64," + AUDIO_B64;`——base64 由变量承载。派生新课时必须替换 `var AUDIO_B64 = "…"` / `var VIDEO_B64 = "…"` 的**变量本体**，src 行保持原样。只改 src 前缀会把新 base64 拼进旧变量，播放内容 = 新素材 + 上一课素材拼接，学员听到的是上一课内容（第 2 课真实事故）。
2. **data URI 视频必须 moov 前置**：ffmpeg 输出 mp4 一律加 `-movflags +faststart`（moov 在文件头）。moov 在文件末尾时，浏览器内嵌 base64 视频报 `DEMUXER_ERROR_NO_SUPPORTED_STREAMS`、duration NaN 无法播放。
3. **生成后验证（三重）**：① 从 HTML 提取 base64 解码回文件，与磁盘源文件逐字节一致；② ffprobe 对时长（音频 = 视频 = FULL_END）；③ 浏览器实测 `audio.duration`（video.duration 在 playwright headless 不可靠——该环境对 file:// 和私有地址媒体有 URL safety check，两课都读不出，属环境限制不是文件问题；视频兜底用「编码参数与上一课可播视频一致 + moov 前置 + 字节一致」判断）。
4. **字幕裁剪上下都查**：横版视频除底部双语硬字幕条外，顶部常有 UP 主中文旁白注释条（如科普弹幕式字幕），抽帧时上下边缘都要确认，必要时 crop 上下同时裁（示例 640x360 源：`crop=640:210:0:45` 保留 y45-255 中间画面）。
5. **说话人多于两人的扩展**：新说话人加 badge 类（`.badge.O` 等）+ JS 渲染三态映射，不要写死双人。

### 盲听视频标准（视频源带硬字幕时的处理）

1. 先抽 1-2 帧确认字幕条坐标（示例：360x480 竖版，硬字幕条在 y320-480）。
2. 用 crop 裁掉字幕条、只留画面主体，同时压小体积：
   `ffmpeg -ss <起> -to <止> -i src.mp4 -vf "crop=360:320:0:0" -c:v libx264 -crf 26 -preset veryfast -pix_fmt yuv420p -c:a aac -b:a 96k -movflags +faststart blind.mp4`
   （crf 按体积微调，30 秒片段目标 ≤1MB；横版视频按实际字幕条坐标裁。）
3. 抽首帧做 poster 小图（jpg），与视频一起 base64 内嵌，避免播放器显示黑屏。
4. 播放器双轨逻辑：盲听按钮播 `<video>`（从头开始）；点精讲任意一句先 `bv.pause()` 再播 `<audio>` cue；video 的 timeupdate 驱动盲听进度条、ended 复位；音量滑块**同时控制 video 与 audio**；空格快捷键排除 VIDEO 焦点。

交付前按 html Skill 跑 `shot.py` 自检（桌面 + 移动截图、console 错误、重叠文本），通过后再用 present_files 交付。

轻量场景（快速回复、聊天内即时练习）可降级为 `type="renderer"` 交互学习卡，按 doubao-visualization（html_svg）输出：三步流程 + 点句解析 + 发音对比，点按 ≥44px，初始静态可读。

## 交付顺序

文本讲解（盲听指引 → 解析表 → 精听脚本）→ present_files 交付单文件 HTML（视频已内嵌，无需单独交音频）。HTML 一次只交付一个，先介绍再交付。
