# 每课交付模板（四步教学法 + 复习闭环）

每次出课按此结构交付，四步缺一不可。语言用学员所用语言（默认中文讲解 + 英文台词）。

## Step 0 · 复习上一课（第 2 次起）

- 开新课前先要求学员用上一课 HTML 页复习：整段盲听重听 → 精听逐句跟读 → 交上节课作业（造句/填空/录音）。
- 批改复习作业，通过才进新课；不通过让学员重练。
- **复习任务下达的同时，并行准备新课**（选片段→核台词→找片源→裁剪音频→做 HTML），学员确认复习完成后一并交付新课页。

## Step 1 · 盲听

- 交付：**内嵌「无字幕视频 + 原声」的单文件 HTML**（present_files 交付整页，不单独交音频）。视频源带硬字幕时，先抽帧确认字幕条位置，用 ffmpeg crop 裁掉字幕条区域再内嵌，保证盲听画面干净无字幕（方法见下方「盲听视频标准」）。
- 给 3-5 个引导问题（谁在说话、在干什么、笑点/情绪在哪、注意哪个发音、结局反转）。
- 要求：看画面听原声 2-3 遍，先不看任何文字。

## Step 2 · 逐句解析

- 交付台词表格：`# | 说话人 | 台词 | 解析`。
- 解析覆盖：发音/连读（写音标或拟音，如 What'd you say → /wʌʤə/）、词汇、句型（如 Let me have some of that…）、文化梗（笑点机制 + 背景）。
- 解析内容必须与实际音频一致；字幕与官方台词有差异时标注。
- 结尾给「知识点小结」：词汇、发音、句型、文化梗四条。
- **例句规范（对齐 SKILL.md 第 1.5 节工作模式）**：
  - **等级匹配**：所有例句按学员 CEFR 等级写（A1-A2 短句高频词 / B1 短句+少量习语 / B2-C1 可上从句生僻梗），不用超纲例句。
  - **总量 ~20 句**：本课精讲区累计可跟读例句（原句 + 扩展例句 + `ex` 扩展块）约 20 句，别贪多也别太薄。
  - **有趣可复用**：例句贴生活/梗/能直接搬去用的口语场景，带点趣味或双关更好；避免教科书死句。
  - **词组/句型必须真实出自本课原句**；扩展词显式标注「本课未出现」。
  - **密度优先**：把 3-5 句核心梗句做厚（缩略/习语/连读 + 例句），不堆稀句。

## Step 3 · 带字幕精听

- 交付：**干净双语脚本**（英文台词逐句 + 中文对照，无解析），即"字幕"。
- 步骤（写清楚让学员照做）：
  1. 对照字幕把音频再听一遍，逐句找到刚才盲听时没听出来的地方，标记；
  2. 跟着音频逐句跟读 2 遍（模仿语气、连读）；
  3. 关掉字幕再裸听 1 遍，确认每一句都能听清。
- 可附填空练习（挖 8 个左右关键词）供自测。

## Step 4 · 监督与反馈（可选，学员同意才建）

1. 问：每天可学多久？几点方便提醒？
2. 按定时任务（如 automation_update 建每日打卡）建每日提醒。
3. 布置作业：填空答案 + 理解题英文回答 + 用本课句型造句（2-3 句）＋（可选）30 秒跟读录音。
4. 学员交作业后：批改、纠音、按表现决定下一课难度（达标升档，不达标重练）。

## 交互学习页（每课默认交付，单文件 HTML）

制作**一个自包含的 .html**（内嵌 base64 视频 + 音频，无外部依赖），把三步收进一页，学员在手机/电脑直接打开：

- **盲听区**：内嵌 `<video>`（**无字幕画面** + 原声）+ 播放按钮 + 引导问题（先不给字幕和解析）。
- **精讲区**：逐句台词卡（条数 = 实际台词数，如 28 条），**点击任意一句播放该句原音**（同一份音频按 cue 时间轴 seek 播放），可展开解析；每句解析含**连读技巧标注**（失爆/同化/弱读/元音+元音连读，写音标或拟音），附发音/知识点对比卡（如 /w/ vs /hw/）。
- **精听区**：逐句播放面板——**语速选择（0.5×/0.75×/1×/1.25×）、上一句/下一句、单句循环**、句内进度条、音量控制。
- 交互规范：播放必须由用户点击触发（禁止自动播放）；按钮 ≥44px；所有按钮挂真实 handler；无 emoji。
- 台词时间轴：**字幕站全文 + 视频硬字幕 OCR + 本地 ASR（faster-whisper base）三重校准**逐句对齐（±0.3 秒误差，页脚注明口径）。

### 生产规避清单（模板派生时必查）

具体工程规范全部以 `references/html-build.md` 为准（结构、视觉、播放器契约、base64 内嵌、生成后验证、常见问题速查），此处只列「派生课页前必做」的 6 条，避免与 html-build.md 重复：

1. **必须从 `assets/lesson-template.html` 派生，禁止另写 JS/样式**——手抄模板极易丢逻辑（第 5 课真实事故：手抄时丢了 prev/next 双向循环，精听最后一句点「下一句」卡住不跳回）。派生后逐字对照模板的播放器逻辑。
2. **base64 变量替换本体 + Python 落盘**：替换 `var AUDIO_B64/VIDEO_B64/POSTER_B64` 的定义处（勿只改 src 前缀）；整段 HTML 用 Python 写盘（PowerShell Set-Content 会把中文写 GBK 乱码 → 整页空白，第 5 课事故）。详见 html-build.md 第 6 节。
3. **data URI 视频 moov 前置**：ffmpeg 输出 mp4 一律 `-movflags +faststart`。
4. **精听音频与视频同窗口裁切**：嵌入的 `<audio>` 必须是场景裁切段音频（时长=视频），勿用整集全长（否则精听句子全错位，第 5 课事故）。详见 clip-selection.md 第 7 节。
5. **生成后三重验证**：base64 字节一致 + 时长一致（含音频窗=视频窗）+ `node -c` JS 语法 + Playwright 实开（渲染/cue 卡/data URI/wrap 行为/截图），全过才交付。详见 html-build.md 第 7 节。
6. **CUES 数据规范**：条数=实际台词句数（非写死的 28 条）；每句 `s/e` 来自 ASR 校准；note 六要素（连读写音标/词汇/常用词组/句型/梗/例句 1-2）；**例句总量全课 ~20 句 + 有趣可复用 + 按学员等级写（见 SKILL.md 第 1.5 节工作模式）**；引用中文词用 `「」` 不用英文双引号；有例句扩展加 `ex` 字段（模板已含「更多例句」渲染块）。

### 盲听视频标准（视频源带硬字幕时的处理）

字幕条怎么遮/裁以 `references/clip-selection.md` 第 6 节为唯一标准（**默认 boxblur 只糊英文行、保留中文行 + `boxblur=10:2:6:2` 参数 + crop 高度偶数 + 上下边缘都查**；crop 整条仅作备选），此处只列「交付前」流程：

1. 按 clip-selection.md 第 6 节处理字幕（模糊或裁），抽帧确认无英文残留。
2. 抽首帧做 poster（jpg，压到 20-50KB），与视频一起 base64 内嵌，避免播放器黑屏。
3. 精听音频按 clip-selection.md 第 7 节裁——**与视频同一时间窗**（时长一致，勿用整集全长）。
4. 播放器双轨逻辑已在模板内实现，**不要改**（盲听播 `<video>` 从头、点句播 `<audio>` cue、音量联动、空格排除 VIDEO 焦点；契约见 html-build.md 第 3 节，含 prev/next 双向循环）。

交付前按 html-build.md 第 7 节跑完整验证（字节一致/时长一致/`node -c`/Playwright 实开），全过再用 present_files 交付。

轻量场景（快速回复、聊天内即时练习）可降级为 `type="renderer"` 交互学习卡，用 html_svg 输出：三步流程 + 点句解析 + 发音对比，点按 ≥44px，初始静态可读。

## 交付顺序

文本讲解（盲听指引 → 解析表 → 精听脚本）→ present_files 交付单文件 HTML（视频已内嵌，无需单独交音频）。HTML 一次只交付一个，先介绍再交付。
