# Ivan Learning · 美漫梗英语带练

用《恶搞之家》(Family Guy) 等美剧/美漫/动画的名场面梗片段，按 **「盲听 → 逐句解析 → 带字幕精听」** 三步流程带练英语听力与口语的 AI Skill。

## 它做什么

- **等级测评**：安装后先询问你的 CEFR 等级（A1–C1）；不知道就做 15 道分级测试题自动定级。
- **选片段**：按等级适配（语速、生词率、连读密度、句式复杂度）挑选《恶搞之家》等名场面，台词先核验（字幕站全文 + 硬字幕 OCR + 云端 ASR 三重校准），再找片源。
- **四步教学**：
  1. **盲听**：内嵌「无字幕视频 + 原声」的互动页，看画面听 2–3 遍，先不看任何文字；
  2. **逐句解析**：每句可点击播放原音，解析覆盖发音连读（失爆/同化/弱读）、词汇、句型、文化梗；
  3. **带字幕精听**：调速（0.5×–1.25×）、上一句/下一句、单句循环，对照字幕逐句跟读；
  4. **监督打卡（可选）**：每日提醒 + 作业批改纠音。
- **复习闭环**：第 2 次及以后开新课前，先发上一课复习入口，批改通过后再收集新课素材。

## 安装

### 方式一：SkillHub（审核通过后）

```bash
skillhub install ivan-learning
```

### 方式二：手动安装

把本仓库的 `SKILL.md` 和 `references/` 放入 Agent 的 skills 目录：

```text
<your_agent_workspace>/.user_skills/ivan-learning/
├── SKILL.md
└── references/
    ├── level-test.md
    ├── clip-selection.md
    └── lesson-template.md
```

然后对 Agent 说：**「用 ivan-learning 带我学英语」** 即可开始。

## 使用流程

```
第 1 次调用：等级测评（自报或测试）→ 记录等级 → 选片段 → 出第 1 课
第 2 次起：  先发上一课复习入口 → 学员复习交作业 → 批改通过 → 再收集新课素材
```

每课交付一个自包含的单文件 HTML 互动页（盲听视频 + 原声 + 逐句解析 + 精听面板全部内嵌，手机/电脑直接打开）。

## 质量保证

- 台词不编造：字幕站全文 + 视频硬字幕 OCR + 云端 ASR 三重校准，逐句对齐（±0.3s）。
- 盲听视频无字幕：视频源带硬字幕时先裁剪掉字幕条区域再内嵌。
- 生产规避清单：base64 变量本体替换、mp4 moov 前置、生成后三重验证等，固化在 `references/lesson-template.md`。
